# Sprint 2
## Como foi a experiência?
>[!IMPORTANT]
>**A sprint 2 me ajudou a melhorar nas consultas ao banco de dados SQL.**
**Alem das consultas aprendi normaliza um banco ja existente e usar os próprios dados no baco normalizado, foi muito instrutivo pois no curso tecnico de informatica a pessoa sempre começa criando o banco do zero.**

## Quanto ao aprendizado

**No curso de SQL para Análise de Dados, tive a oportunidade relembrar como criar tabelas, inserção e atualizaçao das tabelas.**
**Algum bem interessante foi criar o banco e em uma extenção e exporta para extenções diferentes como CSV, ou criar BD em sqlite e exporta em SQL, embora seja simples mas no ambiente academico nao faz com tanta frenguencia, embora vou ter banco de dados no proximo trimestre, no tecnico não faz.**
**Como sempre essa sprint deu aperto necessario na mente para preparar para as próximas sprints que usara teria de banco de dados.**
