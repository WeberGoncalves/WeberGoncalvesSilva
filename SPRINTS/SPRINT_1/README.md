# Sprint 1
## Como foi a experiência?
>[!IMPORTANT]
>**A sprint 1 foi exatamente a tradução para nosso idioma "corrida", corrida para assistir as aulas de Linux corrida para assistir as aulas GitHub e claro corrida para completar o desafio.**
**Por ser a primeira, ela não só ensinou as disciplina da sprint mas também gerenciamento do tempo, evitar procrastinação trabalhar sob demanda.**

## Quanto ao aprendizado

**No curso do Linux tive a oportunidade relembrar os vários comando do  terminal, mas usa-los num script foi algo novo para mim.**
**No curso de GitHub aprendi além dos comandos também muito conceito de gerenciamento de repositório , a importância de manter o servido do projeto atualizado.**
**Essa sprint deu aperto necessario na mente para preparar para as próximas sprints.**
